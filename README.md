# 🎓 Student Feedback Analysis (Simple Project)

## 📌 What is this project?

This project analyzes **student feedback data**.

It shows:

* How students rated
* What they feel (Positive / Neutral / Negative)
* Simple graphs and report

---

## 🛠️ Tools Used

* Python
* Pandas
* Matplotlib
* TextBlob (for sentiment)

---

## 📁 Files Needed

* Dataset: `Student_Satisfaction_Survey.csv`
* Python file: `main.py`

---

## ▶️ How to Run (Easy Steps)

### Step 1: Install Python libraries

Open terminal and run:

```bash
pip install pandas matplotlib textblob vaderSentiment wordcloud fpdf
```

### Step 2: Add dataset

Put CSV file in same folder

### Step 3: Run code

```bash
python main.py
```

---

## 📊 What you will see

* Graph of student ratings 📈
* Sentiment result:

  * Positive 😊
  * Neutral 😐
* WordCloud (most used words)
* PDF report generated

## 🎯 What you learn

* Basic Data Analysis
